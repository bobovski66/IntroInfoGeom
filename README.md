# Introduction to Information Geometry

**The Calculus of Probability Distributions** — a ten-week undergraduate course beginning with replicator differential equations and culminating in Fisher geometry on probability models.

Prerequisites: multivariable calculus, introductory differential equations, and elementary linear algebra. Probability is introduced in the course.

This repository hosts a static course site with HTML readings, interactive demos, guided labs, and checkable weekly quizzes. The first course website implementation is developed on a feature branch before review and publication via GitHub Pages.

## Pedagogical principle

Begin with a familiar ODE; reinterpret its state as a probability distribution; study entropy and relative entropy; derive the Fisher metric from the second-order expansion of KL divergence; finally return to replicator equations as natural-gradient flows when a potential exists.

## Course modules

1. Replicator equations and scalar dynamics
2. Payoff matrices and stability
3. The simplex and three-strategy dynamics
4. Probability distributions as states
5. Entropy, odds, and exponential normalization
6. Relative entropy and Lyapunov stability
7. Fisher information and local geometry
8. Square-root coordinates and spherical geometry
9. Natural gradients and potential-driven evolution
10. The Gaussian family and hyperbolic geometry

Web pages are dependency-light static HTML, CSS, and JavaScript. Mathematical notation uses MathJax via CDN when online.
